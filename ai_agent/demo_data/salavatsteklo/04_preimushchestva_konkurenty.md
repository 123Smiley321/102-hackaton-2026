# Преимущества и конкуренты

Доказуемые тезисы и рамка конкурентного анализа

Разделяет факты, которые можно подтверждать источниками, от гипотез для маркетингового позиционирования. Названия конкурентов намеренно не выдуманы.

Подтверждённые основания для позиционирования

Широта продуктовой линейки на сайте группы: шесть крупных категорий, включая архитектурные, оконные и интерьерные продукты [S2].

История предприятия: первая продукция Салаватского завода технического стекла была выпущена в 1962 году [S4].

Разработки, описанные на официальном сайте: Over Size, Ultraview R и Clearview [S5].

Группа компаний указывает масштаб производства и географию площадок [S1]. Использовать эти данные только с правильной атрибуцией к группе.

Рабочие гипотезы маркетинговых преимуществ

Ассортимент для разных сценариев применения; конкретные продуктовые преимущества нужно привязывать к позиции каталога.

История производственного опыта и развитие технологий — допустимый сюжет контента при наличии ссылки на официальную историю.

Полезные для профессионалов темы: работа со стеклом в архитектуре, особенности покрытий, визуальные решения и корректный выбор по технической задаче.

Конкурентное окружение: что должно делать AI

Сравнивать компании только по открытым проверяемым источникам: ассортимент, описанные продукты, официально опубликованные технические свойства и каналы коммуникации.

Фиксировать дату и ссылку для каждого конкурентного утверждения; не смешивать рекламные заявления с измеряемыми параметрами.

Для MVP достаточно шаблона сравнения; без отдельного исследования список конкретных компаний оставляется пустым.

Матрица сравнения (шаблон)

Поля: конкурент / официальный URL / продуктовая категория / наличие проверенного аналога / важное отличие / дата проверки / степень уверенности.

Запрещено автоматически утверждать «лучше конкурентов», «№1», «самое прочное» или «самая низкая цена» без подтверждения и юридической проверки.

Утверждённый менеджером конкурентный обзор после валидации добавляется в базу знаний отдельным файлом.
