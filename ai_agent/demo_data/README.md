Демо-материалы для проверки агента.

salavatsteklo/ — пакет материалов для MVP от Лизы (задача 8), подготовлен 14.11.2026, факты сверены по официальным источникам salstek.ru [S1]–[S5]. Шесть документов базы знаний (01–06), профиль для админки (profile.json: сегменты ЦА и CTA, тон, правило «показатели группы — не показатели АО», стиль и подпись изображения) и PDF «Паспорт компании» (визуальная версия тех же сведений, в базу знаний не загружается, чтобы не дублировать фрагменты).

Метки [S1]–[S5] внутри документов — ссылки на официальные источники компании. Агент свои фрагменты базы знаний помечает [K1], [K2]…, чтобы их не путать.

В пакете company_id указан как salavatsteklo_demo; в системе ID компаний — UUID, сопоставление делает бэкенд при создании компании.

company_b/o_kompanii.md — выдуманная кофейня для проверки изоляции компаний (критерий 9). В ней «секретный» факт «Лавандовый раф Б-42», который не должен всплывать в ответах для Салаватстекла.
