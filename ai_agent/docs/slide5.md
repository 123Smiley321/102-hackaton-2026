# Слайд 5. Агент и контент (Т4, Т5, Т7) — тезисы от Р2

Заголовок: Агент знает бизнес и бренд; ничего не публикует без апрува

Левая колонка — «Знает бизнес»
- Администратор загружает документы и сайт → у каждой компании своя база знаний в отдельном хранилище
- Агент сам выделяет продукты, аудиторию, преимущества
- В каждом черновике — ссылки на фрагменты [K1], [K2] и официальные источники salstek.ru [S1]–[S5]: видно, откуда взят каждый факт

Центр — «Пишет в стиле бренда»
- Промпт-контракт v1: только факты из материалов, тон бренда, без рекламных обещаний
- Текст + иллюстрация с пометкой «AI-иллюстрация» под площадку (Telegram / ВК / MAX)
- Автопроверка перед согласованием: убирает «лучший/гарантируем», ловит числа, которых нет в материалах, следит за длиной

Правая колонка — «Помнит»
- История диалога и решения клиента сохраняются и переживают перезапуск
- «Сделай следующий пост об этом же продукте» — агент сам понимает тему и прошлые замечания

Внизу плашка: Любой материал — черновик. Публикация только после кнопки «Одобрить» (Р1)

Скрины: (1) сообщение «использованы факты: … источник salstek.ru/…», (2) черновик v1 и v2 после замечания, (3) ответ с полем engine — какая модель отвечала (ChatGPT / YandexGPT / offline)
